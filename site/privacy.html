What this site does

This portfolio is a static website. It serves the same files to everyone and does not run any code that identifies or profiles visitors.

What it does not do

There are no forms, cookies, analytics scripts, tracking pixels, advertising networks, accounts, or logins anywhere on this site. Fonts and images are self-hosted, so your browser never contacts a third-party font or CDN service from these pages. The only data exchange that happens is the one you initiate yourself: a mailto: link opening your own email client with the address prefilled.
