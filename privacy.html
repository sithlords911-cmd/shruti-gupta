Privacy

Privacy.

A short, honest note: this site exists to show the work, nothing more. Nothing here collects, stores, or sells your data.

What this site does

This portfolio is a static website. It serves the same files to everyone and does not run any code that identifies or profiles visitors.

What it does not do

There are no forms, cookies, analytics scripts, tracking pixels, advertising networks, accounts, or logins anywhere on this site. Fonts load from Google Fonts and images are self-hosted — your browser contacts Google only to fetch the typefaces, the same way any site using web fonts does. The only data exchange that happens is the one you initiate yourself: a mailto: link opening your own email client with the address prefilled.
